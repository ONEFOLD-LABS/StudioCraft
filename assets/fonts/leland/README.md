# Leland (music font)

`Leland.otf` is the Leland music font, version 0.80, by MuseScore Limited, licensed under the
SIL Open Font License 1.1 (`OFL.txt`). It follows the Standard Music Font Layout (SMuFL).
StudioCraft embeds it unmodified to draw the score editor (`crates/ui/src/score/view.rs`).

Source: the `fonts/leland` folder of the MuseScore repository on GitHub
(github.com/musescore/MuseScore).
